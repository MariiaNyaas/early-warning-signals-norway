Economic impact

Decision framework

  1. Review sectors with rising absolute counts.
  2. Validate against active-enterprise denominators and industry exposure.
  3. Investigate co-movement with financing costs, sales and employment.
  4. Only then calibrate thresholds using historical out-of-sample testing.

Methodology & limitations

This version compares published SSB counts. Year-on-year comparisons use matching third quarters; other charts show Q4 2025–Q3 2026. Counts by industry exclude sole proprietorships, while regional counts include all categories. These populations must not be interchanged.

Turnover (NOK thousands) and persons employed are reported for enterprises in bankruptcy proceedings, not estimates of economic losses or displaced employment. Suppressed cells (“..”) are not treated as zero. The supplied share-capital file places all 2026 AS/ASA bankruptcies in the “more than NOK 500,000” category, an apparent comparability anomaly, so it is excluded.

No active-enterprise denominators, validated leading variables, lag study or backtest are present yet. It would therefore be premature to claim that the dashboard predicts bankruptcy risk. The next research version will address those requirements.
